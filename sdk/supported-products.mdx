## Photo Requirements by Product

### Face Photo Required

These products overlay onto the face or neck area.

| Product | `productType` |
|---|---|
| Sunglasses | `sunglasses` |
| Eyeglasses | `eyeglasses` |
| Necklaces / jewellery | `jewellery` |
| Earrings | `earrings` |
| Lipstick | `makeup_lipstick` |
| Foundation | `makeup_foundation` |
| Mascara | `makeup_mascara` |

<Info>Accepted categories: `male_face_closeup`, `female_face_closeup`, `kid_boy_face_closeup`, `kid_girl_face_closeup`</Info>

---

### Full Body Photo Required

These products are placed on the full body.

| Product | `productType` | Gender restriction |
|---|---|---|
| Men's clothing | `mens_clothing` | Male only |
| Women's clothing | `womens_clothing` | Female only |
| Kids' clothing | `kids_clothing` | Child only |
| Shoes / sneakers | `footwear` | Any gender |
| Handbags / purses | `bags` | Any gender |

---

### Room Photo Required

These products are placed into a room scene. The user uploads a photo of their room instead of a person photo.

| Product | `productType` | Room type detected |
|---|---|---|
| Bedroom furniture | `bedroom_furniture` | Bedroom |
| Living room furniture | `living_room_furniture` | Living room |
| Dining room furniture | `dining_room_furniture` | Dining room |

<Info>Accepted categories: `room_bedroom`, `room_living_room`, `room_dining_room`</Info>

The SDK automatically detects the room type from the uploaded photo using on-device AI (YOLOv11 object detection). The user does not need to label their photo.

## TypeScript Types

`productType` is **open** — it accepts any string and is forwarded to HP as a descriptive label. The well-known values below are examples, not an exhaustive list. You can pass values like `"tops"`, `"dresses"`, or `"co-ords"` freely.

```ts
// productType is string — any value is accepted
// Well-known examples:
"sunglasses" | "eyeglasses"
"mens_clothing" | "womens_clothing" | "kids_clothing"
"footwear"
"jewellery" | "earrings"
"bags"
"makeup_lipstick" | "makeup_foundation" | "makeup_mascara"
"bedroom_furniture" | "living_room_furniture" | "dining_room_furniture"
"bathroom_furniture" | "kitchen_furniture" | "home_decor"
```

`HpCategory` is a **required** field on every `personalize()` call. It determines which HP pipeline runs.

```ts
type HpCategory =
  | "clothing"
  | "footwear"
  | "eyewear"
  | "jewellery"
  | "accessories"
  | "makeup"
  | "furniture";
```

## Checking Eligibility

```ts
const eligibility = await sdk.getEligibility("sunglasses");

if (eligibility.eligible) {
  // Show Try On button
} else {
  switch (eligibility.reason) {
    case "REQUIRED_USER_IMAGE_MISSING":
      // User hasn't uploaded the right photo yet
      break;
    case "PRODUCT_TYPE_UNSUPPORTED":
      // Phase 2 product — not yet available
      break;
    case "PRODUCT_TYPE_NOT_FOUND":
      // productType was not provided
      break;
  }
}
```

## HP Routing

When you call `sdk.personalize(...)`, the SDK sends your `category` (`HpCategory`) directly to HP as the routing field, and your `productType` string as the label. You supply both — the SDK does not infer one from the other.

| What you pass (`category`) | What HP routes to | Example `productType` values |
|---|---|---|
| `"eyewear"` | Eyewear try-on pipeline | `"sunglasses"`, `"eyeglasses"` |
| `"clothing"` | Clothing try-on pipeline | `"mens_clothing"`, `"womens_clothing"`, `"tops"`, `"dresses"`, `"co-ords"` |
| `"footwear"` | Footwear try-on pipeline | `"footwear"`, `"sneakers"`, `"boots"` |
| `"jewellery"` | Jewellery try-on pipeline | `"jewellery"`, `"earrings"`, `"necklace"` |
| `"accessories"` | Accessories try-on pipeline | `"bags"`, `"handbag"`, `"clutch"` |
| `"makeup"` | Makeup try-on pipeline | `"makeup_lipstick"`, `"makeup_foundation"`, `"makeup_mascara"` |
| `"furniture"` | Room generation pipeline | `"bedroom_furniture"`, `"living_room_furniture"`, `"dining_room_furniture"` |
